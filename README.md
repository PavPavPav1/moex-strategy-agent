# MOEX Strategy Agent

Учебный агент, который переводит описание long-only SMA-стратегии с естественного языка в проверенную спецификацию, запускает бэктест на дневных данных **MOEX ISS**, считает метрики, находит слабые режимы и показывает новости рядом с резкими движениями цены — **без утверждений о причинности**.

> **Это не инвестиционная рекомендация.** Прошлая доходность не гарантирует будущую. Не моделируются налоги, дивиденды, проскальзывание и ограничения ликвидности.

## Что уже работает

- 3 инструмента с JSON-схемами, валидацией Pydantic, понятными ошибками и ограниченными результатами.
- Агентный цикл: максимум 6 шагов, защита от повторного цикла, таймауты, не более 2 технических попыток, журнал `trace.jsonl`.
- Исторические свечи MOEX ISS с пагинацией, локальным кэшем, SHA-256 и восстановлением из маркированного снапшота при сбое сети.
- Бэктест без look-ahead: сигнал по `close` дня T, сделка по `open` дня T+1.
- Целое число акций, комиссия на покупку и продажу, принудительное закрытие позиции в конце периода.
- Кривая капитала, просадка, CAGR, волатильность, Sharpe, сделки, win rate, profit factor, exposure и сравнение с «купить и держать».
- Независимая реализация на pandas/NumPy: сравнение **каждой точки капитала и каждой сделки**; при расхождении отчёт не выдаётся.
- Диагностика слабых мест по метрикам и календарным годам.
- RSS-интеграция с лимитами и ошибками по каждой ленте; офлайн-подборка реальных открытых публикаций отдельно маркируется.
- Самодостаточный HTML-отчёт, Markdown, CSV, JSON и оформленная PDF-презентация.

## Быстрый запуск

Требуется Python 3.9+.

```bash
cd moex-strategy-agent
python3 -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"

# Полное офлайн-демо на реальном снапшоте MOEX ISS
moex-agent demo --cache-only

# Тот же сценарий + обработанный таймаут инструмента
moex-agent demo --cache-only --fault backtest_moex_strategy=timeout

# Проверки
pytest
```

Откройте [`reports/demo_sber/report.html`](reports/demo_sber/report.html). Основные файлы:


## Своя стратегия

```bash
moex-agent run "Газпром, GAZP, 2024-01-01 — 2025-12-31. Покупай, если SMA(10) > SMA(30), продавай при обратном условии. Капитал 500000, комиссия 10 б.п."
```

Если период, окна, капитал или комиссия не заданы, агент использует явно перечисленные допущения. Неподдерживаемые шорт, плечо, стопы и произвольные индикаторы отклоняются с подсказкой, а не имитируются.

Для обновления котировок и RSS из сети:

```bash
moex-agent demo --online
```

Если сеть недоступна, но точный снапшот уже есть, используется кэш с предупреждением `iss_cache_after_error`. Если данных нет, агент честно завершается ошибкой и не выдумывает метрики. Прямой сетевой запуск зависит от доступности `iss.moex.com` и RSS с машины пользователя; офлайн-сценарий воспроизводится без сети.

## Результат демо SBER

Условия: 2024-01-01 — 2025-12-31, SMA 20/50, 1 000 000 ₽, 5 б.п. на операцию, 510 торговых сессий.

| Метрика | SMA 20/50 | Купить и держать |
|---|---:|---:|
| Итоговый капитал | 976 041 ₽ | 1 101 849 ₽ |
| Доходность | **−2,40%** | **+10,18%** |
| CAGR | −1,21% | +4,99% |
| Максимальная просадка | −15,52% | −32,03% |
| Волатильность, годовая | 14,27% | 23,55% |
| Sharpe, rf=0 | −0,01 | 0,30 |
| Закрытые сделки | 7 | 1 |
| Win rate | 14,29% | — |
| Время в позиции | 47,45% | 99,80% |

**Вывод по этому периоду:** стратегия снизила волатильность и максимальную просадку, но отстала от buy & hold на **12,58 п.п.** Шесть из семи закрытых сделок убыточны; 2024 год −3,61%, 2025 год +1,26%. Это повод исследовать режимы и устойчивость параметров, а не подгонять окна до красивой доходности.

Независимая сверка: **PASS**, 510 точек, 7 сделок, максимальное расхождение капитала и PnL — **0,00 ₽**. Подробности: [`crosscheck.json`](reports/demo_sber/crosscheck.json).

## Провайдер и модель

По умолчанию `config/agent.json` использует `scripted` — детерминированную заглушку для воспроизводимого демо, которую лекция разрешает при отладке цикла.

Для OpenAI-совместимого GigaChat API измените только конфиг:

```json
{
  "provider": "openai_compatible",
  "model": "GigaChat-2-Max",
  "base_url": "https://gigachat.devices.sberbank.ru/api/v1/chat/completions",
  "api_key_env": "LLM_API_KEY"
}
```

Задайте access token в переменной окружения `LLM_API_KEY`. Реальные ключи не входят в проект; [`.env.example`](.env.example) содержит только имя переменной. Адаптер возвращает понятную ошибку при недоступности провайдера. Живой вызов GigaChat не входил в проверку без токена.

## Методика бэктеста

1. На закрытии дня T вычисляются простые скользящие средние по доступным ценам `close`.
2. Если `SMA fast > SMA slow`, целевое состояние — long; иначе — денежные средства.
3. Состояние реализуется по `open` следующей торговой сессии. Это исключает использование будущей цены.
4. Покупается `floor(cash / (open × (1 + fee)))` акций. Комиссия взимается с каждого оборота.
5. Капитал ежедневно равен `cash + shares × close`. Последняя позиция закрывается по последнему `close`.
6. Buy & hold покупает на первом `open` и продаёт на последнем `close` с той же комиссией.
7. Sharpe использует дневные доходности, rf=0 и √252. Дивиденды и налоги не учитываются; скачки на дивидендных отсечках остаются в ценовом ряду и обязательно отмечаются как ограничение.

Независимая реализация в `src/moex_agent/validation.py` заново строит сигналы через `pandas.rolling`, отдельно моделирует денежный цикл и не импортирует функции основного движка.

## Новости и причинность

Онлайн-источники перечислены в `config/rss_sources.json`. Инструмент берёт до 100 записей на ленту, очищает HTML, сопоставляет дату ±N дней и название компании/тикер, возвращает не более трёх ссылок на движение.

Для офлайн-демо `data/news_snapshot.json` содержит **небольшую подборку реальных открытых публикаций, а не полный RSS-архив**. Например:

- [Интерфакс, 20.12.2024](https://www.interfax.ru/business/999819) — рынок и решение ЦБ;
- [Интерфакс, 11.07.2024](https://www.interfax.ru/business/970295) — дивидендная отсечка Сбербанка;
- [ПРАЙМ, 12.02.2025](https://1prime.ru/20250212/sberbank-854887500.html) — публикация о динамике акций.

Формулировка в каждом совпадении: **«Календарное и лексическое совпадение; причинно-следственная связь не установлена»**. Заголовки новостей могут сами содержать интерпретации автора; агент не принимает их как доказанную причину.

## Демонстрация на 3 минуты

1. **0:00–0:30** — показать запрос и три контракта: `moex-agent contracts`.
2. **0:30–1:30** — запустить `moex-agent demo --cache-only --fault backtest_moex_strategy=timeout`.
3. **1:30–2:00** — показать в терминале `timeout → технический повтор → восстановлено`, затем `trace.jsonl`.
4. **2:00–2:40** — открыть HTML: доходность, просадка, 7 сделок, buy & hold, `PASS` независимой сверки.
5. **2:40–3:00** — показать новости и предупреждение о причинности, завершить ограничениями и дисклеймером.
